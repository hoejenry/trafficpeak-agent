Getting started

  • Click a database in the sidebar to load its tables
  • Click a table to auto-fill a SELECT * query
  • Always use fully-qualified database.table — e.g. nuclearregula.logs
  • Filter on reqTimeSec directly: reqTimeSec >= now() - INTERVAL 1 HOUR
  • Max time range is 6 hours — wrapping reqTimeSec in a function is rejected
  • Do not pass a separate database field — include it in the SQL only
  • Press ⇧ Enter or click Run to execute

✦ Best Practices

Combining three things produces the fastest, most useful queries:

  • Name the exact table — e.g. logs.cdn_request_logs not just "logs"
  • Use an explicit time range — e.g. "last hour" triggers primary-key optimizations
  • Request timestamp ordering — "ordered by most recent timestamp" improves performance
Optimal pattern
Query the logs table from the nuclearregula database for all HTTP errors in the last hour, ordered by most recent timestamp.

◈ Example Queries

Copy these into the Explorer and run. All use real column names from nuclearregula.logs.

⚠ Max time range: 6 hours (21,600 s). Always filter on reqTimeSec directly — no function wrapping on the left side. Do not pass a separate database argument; use fully-qualified database.table in SQL.

-- Top URLs by request count (last 6 hours)
SELECT reqPath, count() AS hits
FROM nuclearregula.logs
WHERE reqTimeSec >= now() - INTERVAL 6 HOUR
GROUP BY reqPath
ORDER BY hits DESC
LIMIT 20
-- Error rate by HTTP status code (last hour)
SELECT statusCode, count() AS n
FROM nuclearregula.logs
WHERE reqTimeSec >= now() - INTERVAL 1 HOUR
GROUP BY statusCode
ORDER BY n DESC
-- Requests per minute time-series (last hour)
SELECT toStartOfMinute(reqTimeSec) AS minute,
       count() AS requests,
       countIf(statusCode >= 400) AS errors
FROM nuclearregula.logs
WHERE reqTimeSec >= now() - INTERVAL 1 HOUR
GROUP BY minute
ORDER BY minute ASC
-- P95 response time by edge server country (last 6 hours)
SELECT serverCountry,
       quantile(0.95)(turnAroundTimeMSec) AS p95_ms,
       count() AS requests
FROM nuclearregula.logs
WHERE reqTimeSec >= now() - INTERVAL 6 HOUR
  AND turnAroundTimeMSec IS NOT NULL
GROUP BY serverCountry
ORDER BY p95_ms DESC
LIMIT 20
-- Top source countries by bandwidth (last 6 hours)
SELECT country,
       round(sum(bytes) / 1e9, 2) AS gb_sent,
       count() AS requests
FROM nuclearregula.logs
WHERE reqTimeSec >= now() - INTERVAL 6 HOUR
  AND country IS NOT NULL
GROUP BY country
ORDER BY gb_sent DESC
LIMIT 10
-- Cache hit rate by content type (last hour)
SELECT rspContentType,
       countIf(cacheStatus = 1) AS hits,
       count() AS total,
       round(countIf(cacheStatus = 1) / count() * 100, 1) AS hit_pct
FROM nuclearregula.logs
WHERE reqTimeSec >= now() - INTERVAL 1 HOUR
  AND rspContentType IS NOT NULL
GROUP BY rspContentType
ORDER BY total DESC
LIMIT 15

🔑 Authentication & Token Notes

  • TrafficPeak accepts a Grafana Service Account token (glsa_…) or an EdDSA JWT (eyJ…)
  • Tokens are JWTs — check expiry via the exp field in any JWT decoder (e.g. jwt.io)
  • A leaked token grants read-only SQL access only — no write path or privilege escalation exists
  • Rotate any exposed token via your TrafficPeak admin panel; update the saved account here with the new token
  • Each saved account maps to one TrafficPeak instance URL + token pair — use separate accounts for different regions (e.g. ord, grafana-us)
